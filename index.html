개인정보처리방침

XR Media Center는 계정, 광고 및 개발자가 운영하는 원격 분석 서비스를 사용하지 않습니다. 앱은 콘텐츠를 제공하지 않으며 사용자가 선택한 미디어만 재생합니다.

기기에 저장되는 정보

앱은 SMB/WebDAV 접속정보, 사용자가 등록한 AI 공급자 설정과 API 키, 최근 재생·즐겨찾기·재생 위치·파일별 화면 및 자막 설정, 생성/가져온 자막, 음성인식 모델, 캐시와 로컬 진단정보를 앱 전용 저장공간에 보관할 수 있습니다. 자격증명과 API 키는 Android Keystore 기반으로 암호화됩니다.

미디어와 네트워크

로컬, SMB 또는 WebDAV 미디어를 열면 기기가 사용자가 지정한 저장소와 직접 통신합니다. SinbhLAB은 미디어를 수신하거나 중계하지 않습니다. 해당 저장소 운영자의 정책과 접속 로그가 적용될 수 있습니다.

선택형 음성인식과 번역

외부 공급자를 설정하지 않으면 번역 요청을 전송하지 않습니다. 기기용 SenseVoice를 선택하면 음성을 기기에서 처리합니다. 사용자가 외부 서비스를 직접 등록하고 동의한 경우, 선택한 기능에 필요한 짧은 오디오 조각, 인식된 대사, 제한된 이전 문맥, 대상 언어·시간정보 또는 자막 이미지를 해당 공급자에게 직접 전송할 수 있습니다. 공급자의 보관·학습·결제·계정 정책이 적용됩니다.

보관과 삭제

0.1.x는 Android 클라우드 백업과 기기 이전 복원을 사용하지 않습니다. 정상 업데이트는 데이터를 유지하지만, 앱 내에서 프로필을 삭제하거나 Android 설정에서 저장공간을 지우거나 앱을 제거하면 해당 기기의 앱 데이터가 삭제됩니다. SinbhLAB 서버에 앱 계정이나 미디어 사본은 보관되지 않습니다.

진단, 보안과 대상 연령

진단정보는 기본적으로 기기에만 저장되며 비밀번호, API 키 또는 인증 헤더를 포함하지 않아야 합니다. 앱의 출시 대상 연령은 18세 이상이며 어린이를 대상으로 설계하거나 홍보하지 않습니다. 어린이를 위한 콘텐츠를 제공하거나 의도적으로 아동 개인정보를 수집하지 않으며, 사용자가 재생하는 미디어의 적합성은 사용자의 책임입니다.

Privacy Policy

XR Media Center uses no app account, advertising, or developer-operated remote analytics. It does not provide content and plays only media selected by the user.

Data stored on the device

The app may store SMB/WebDAV connection details, user-configured AI provider settings and API keys, recent items, favorites, playback position, per-file display/subtitle settings, generated or imported subtitles, speech-recognition models, caches, and local diagnostics in app-private storage. Credentials and API keys are protected with Android Keystore-backed encryption.

Media and network connections

When Local, SMB, or WebDAV media is opened, the device communicates directly with storage selected by the user. SinbhLAB does not receive or proxy the media. The storage operator's policies and access logs may apply.

Optional speech recognition and translation

No translation request is sent without a configured provider. Device SenseVoice processes audio locally. If the user registers and consents to an external service, the app may send required short audio segments, recognized dialogue, limited preceding context, target language/timing metadata, or subtitle images directly to that provider. The provider's retention, training, billing, and account policies apply.

Retention and deletion

Version 0.1.x disables Android cloud backup and device-transfer restore. Normal updates preserve data. Removing profiles in the app, clearing storage in Android settings, or uninstalling the app removes applicable app data from that device. No XR Media Center account or media copy is retained on a SinbhLAB server.

Diagnostics, security, and audience

Diagnostics remain local by default and must not contain passwords, API keys, or authorization headers. The release target audience is users aged 18 and over. The app is not designed or marketed for children, does not provide child-directed content, and does not intentionally collect children's personal data. Users are responsible for the suitability of selected media.

プライバシーポリシー

XR Media Centerはアプリ用アカウント、広告、開発者運営のリモート分析を使用しません。コンテンツを提供せず、ユーザーが選択したメディアのみを再生します。

端末に保存する情報

SMB/WebDAV接続情報、ユーザーが設定したAI提供者とAPIキー、最近の項目、お気に入り、再生位置、ファイル別の画面・字幕設定、字幕、音声認識モデル、キャッシュ、ローカル診断情報をアプリ専用領域に保存する場合があります。認証情報とAPIキーはAndroid Keystoreで暗号化します。

メディアとネットワーク

Local、SMB、WebDAVを開くと端末はユーザー指定の保存先と直接通信します。SinbhLABはメディアを受信・中継しません。保存先運営者のポリシーとアクセスログが適用される場合があります。

任意の音声認識・翻訳

外部提供者を設定しない限り翻訳要求は送信しません。端末用SenseVoiceは端末内で処理します。ユーザーが外部サービスを登録して同意した場合、必要な短い音声、認識文、限定された直前文脈、対象言語・時刻情報、字幕画像をその提供者へ直接送る場合があります。提供者の保存・学習・課金・アカウント方針が適用されます。

保存と削除

0.1.xはAndroidクラウドバックアップと端末移行復元を無効にします。通常更新ではデータを維持します。アプリ内でのプロファイル削除、Android設定でのデータ消去、アンインストールにより対象データが端末から削除されます。SinbhLABサーバーにアプリアカウントやメディアのコピーは保存しません。

診断・安全性・対象年齢

診断情報は原則端末内に保存し、パスワード、APIキー、認証ヘッダーを含めません。本アプリの公開対象は18歳以上で、子ども向けに設計・宣伝していません。子ども向けコンテンツを提供せず、子どもの個人情報を意図的に収集しません。選択したメディアの適切性はユーザーが判断します。

隐私政策

XR Media Center 不使用应用账号、广告或开发者运营的远程分析服务。本应用不提供内容，只播放用户选择的媒体。

设备上保存的数据

应用可能在私有存储中保存 SMB/WebDAV 连接信息、用户配置的 AI 服务与 API 密钥、最近播放、收藏、播放进度、每个文件的画面/字幕设置、字幕、语音识别模型、缓存和本地诊断信息。凭据与 API 密钥使用 Android Keystore 加密。

媒体与网络连接

打开本地、SMB 或 WebDAV 媒体时，设备会直接连接用户指定的存储。SinbhLAB 不接收或转发媒体；存储运营方的政策和访问日志可能适用。

可选语音识别与翻译

未配置外部服务时不会发送翻译请求。设备版 SenseVoice 在本机处理音频。用户注册外部服务并同意后，应用可能向该服务直接发送所需的短音频、识别文本、有限的前文、目标语言/时间信息或字幕图片。该服务的保存、训练、计费和账号政策适用。

保留与删除

0.1.x 禁用 Android 云备份和设备迁移恢复。正常更新会保留数据。在应用中删除配置、通过 Android 设置清除存储或卸载应用，会从该设备删除相应数据。SinbhLAB 服务器不保存应用账号或媒体副本。

诊断、安全与适用人群

诊断信息默认仅保存在设备上，不应包含密码、API 密钥或授权标头。本应用的发布目标用户为18岁及以上，不面向儿童设计或宣传，不提供面向儿童的内容，也不会故意收集儿童个人信息。用户应自行判断所选媒体是否适宜。
